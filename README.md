# Image Hosting Repository

Đây là repository chứa các hình ảnh để sử dụng làm hosting ảnh.

## Cách sử dụng

### Truy cập hình ảnh trực tiếp
Bạn có thể truy cập hình ảnh trực tiếp thông qua URL:
```
https://raw.githubusercontent.com/[username]/[repository-name]/main/item/[filename]
```

Ví dụ:
```
https://raw.githubusercontent.com/yourusername/hz-images/main/item/304crate.png
```

### Sử dụng với GitHub Pages
Repository này có thể được sử dụng với GitHub Pages để tạo một gallery hình ảnh trực tuyến.

## Cấu trúc thư mục
- `item/` - Chứa tất cả các file hình ảnh (PNG, SVG)

## Lưu ý
- Tất cả hình ảnh được lưu trữ dưới dạng raw files trên GitHub
- Có thể sử dụng làm CDN cho các dự án web
- Hỗ trợ các định dạng: PNG, SVG
